# ssh-kit 公開ページ

- [プライバシーポリシー](https://ron0401.github.io/ssh-kit-webpages/privacy.html)
- [サポート](https://ron0401.github.io/ssh-kit-webpages/support.html)

GitHub Pages で main ブランチのルートを公開します。
外部スクリプト・広告・独自のアクセス解析は使用していません。

本文と連絡先の更新時は、ssh-kit アプリ側の `SSHKit/PrivacyPolicy.txt` と
`SSHKit/Publication.json` を更新し、`scripts/prepare-publication.py` で生成した
`privacy.html` と `support.html` をこのリポジトリへコピーしてください。
`index.html` は `support.html` と同じ内容です。
